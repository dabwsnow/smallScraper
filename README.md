# Book Scraper (books.toscrape.com)

ООП парсер для книжкового сайту https://books.toscrape.com/

## Функціонал
- `get_categories()` — вилучає список усіх 50 категорій сайту
- `get_books_from_page()` — вилучає дані про книги з однієї сторінки
- `get_all_books()` — реалізує пагінацію по всіх сторінках сайту (1000+ книг)

## Запуск
```bash
python main.py
```
